# Release Checklist — 5-Axis Slicer MVP

> **This software produces PROTOTYPE output.**
> No unattended-print authorization exists.
> Every G-code download requires an operator to complete the physical dry-run checklist below.

---

## Safety Labeling Scheme

| Label | Meaning |
|---|---|
| `PROTOTYPE - USE WITH CAUTION` | Output generated by prototype software. Operator must inspect before use. |
| `PRODUCTION - VERIFIED` | Reserved for future verified production pipelines. **Not currently achievable.** |
| `UNSAFE - BLOCKED BY DIAGNOSTICS` | Blocking diagnostics detected. Export is denied. |

---

## Mandatory Pre-Print Physical Dry-Run Checklist

Before downloading any G-code output, the operator **must** acknowledge every item below through the `POST /jobs/{job_id}/release-gate` API endpoint:

### 1. Homing Verified
- [ ] Machine has been homed on **all axes** (X, Y, Z, and any rotary axes A/B/C).
- [ ] Homing sensors/switches have been tested and are functioning.

### 2. Center Position Confirmed
- [ ] Workpiece is centered and securely clamped.
- [ ] Workholding fixtures are inspected for interference with tool paths.

### 3. A/B Zero Convention Checked
- [ ] The A and B axis zero positions match the conventions defined in the machine profile.
- [ ] If using a tilting-rotary table (BC_TABLE), confirm B=0 means the table is horizontal.

### 4. Rotary Mapping Reviewed
- [ ] The rotary axis mapping has been visually reviewed against the model orientation.
- [ ] The direction conventions (positive rotation direction) match the profile.
- [ ] **WARNING**: Unverified U/V-to-A/B axis mapping is explicitly blocked by this software.

### 5. Table Clearance Checked
- [ ] Table clearance has been verified for the full rotation envelope of the workpiece.
- [ ] No fixtures, clamps, or cables will interfere with rotary motion.

### 6. Travel Limits Validated
- [ ] Machine travel limits (soft limits and hard limits) have been verified.
- [ ] The G-code bounding box fits within the machine's working envelope.

### 7. Firmware Behavior Acknowledged
- [ ] Firmware behavior on limit violation is documented (e.g., emergency stop, soft-limit hold).
- [ ] Feed rate overrides and safety interlocks are understood.
- [ ] If using Klipper, confirm that `[danger_settings]` are not overriding safety defaults.

### 8. Prototype Label Acknowledged
- [ ] Operator acknowledges that **all output from this software is labeled PROTOTYPE**.
- [ ] Operator understands that collision detection is heuristic/not-implemented and must not be relied upon.
- [ ] Operator will perform a dry-run (air cut) before cutting material.

---

## Dry-Run Procedure for First-Time Profiles

1. Load the G-code with feed rate override set to **0%** (or use single-block mode).
2. Visually confirm that the tool path matches the expected geometry.
3. Gradually increase feed rate override while monitoring for unexpected behavior.
4. If any axis moves unexpectedly, **immediately press the emergency stop**.
5. After a successful dry run, the operator may proceed with the actual cut.

---

## Excluded Capabilities

The following capabilities are **explicitly excluded** from this MVP release:

- **Support generation**: No automatic support structures are generated.
- **Continuous 5-axis slicing**: Only indexed (3+2) slicing is supported.
- **Generalized inverse kinematics**: Only `BC_TABLE` convention is supported.
- **Swept-volume collision detection**: Only heuristic bounding-box checks are performed.
- **Unverified axis mapping**: U/V-to-A/B mapping is blocked and returns `NOT_IMPLEMENTED`.

Any API endpoint or UI element referencing these capabilities will return an explicit `NOT_IMPLEMENTED` or `UNSUPPORTED` status.
